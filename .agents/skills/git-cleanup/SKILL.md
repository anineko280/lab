# Git クリーンアップスキル (`git-cleanup`)

このスキルは、作業完了後に溜まった不要な **ローカルブランチ**、**Git worktree**、および **リモートブランチ（origin）** を安全に整理・削除するためのワークフローです。

誤削除を防ぐための厳格な安全チェック機構と、実行前の対話確認プロセスを備えています。

---

## 🛡️ 安全・保護ポリシー（最重要）

1. **保護ブランチの完全除外**:
   - `main`, `master`, `develop`, `development`, `release/*`, `staging`, `production`
   - 現在チェックアウト中のアクティブブランチ
   - 上記に一致するブランチは**いかなる場合も自動削除しません**。
2. **Worktree の未コミット変更チェック**:
   - 未コミットの変更（staged / unstaged / untracked files）が存在する worktree は削除を**ブロックし、警告を出してスキップ**します。紐づくブランチも保護されます。
3. **対話型承認プロセス**:
   - 必ず事前に **Dry-Run（一覧検出）** を行い、削除対象とスキップ対象を明確にユーザーへ提示して承認を得てから削除（`--execute`）を実行します。

---

## 🧭 クリーンアップ ワークフロー

```
【ステップ1: リモート参照の更新と Dry-Run スキャン】
   │  git fetch --prune 実行と不要リソースの検出
   ▼
【ステップ2: 削除候補とスキップ対象の一覧提示】
   │  ユーザーに削除対象（ローカル・Worktree・リモート）を明示
   ▼
【ステップ3: ユーザーの承認確認】
   │  ユーザーからの実行指示（Proceed）を待つ
   ▼
【ステップ4: 安全な削除実行と結果報告】
   └─ Worktree 削除 → ローカルブランチ削除 → リモートブランチ削除
```

---

## 実行手順

### ステップ 1: Dry-Run スキャンの実行

対象リポジトリで以下のスクリプトを呼び出して、現在のクリーンアップ対象をスキャンします。**デフォルトでローカル、Worktree、およびリモートブランチ（origin）のすべてがスキャン対象** になります。

```bash
# ローカルブランチ、Worktree、リモートブランチの一括スキャン (デフォルト)
.agents/skills/git-cleanup/scripts/cleanup.sh --dry-run

# リモートブランチを除外し、ローカルのみをスキャンする場合
.agents/skills/git-cleanup/scripts/cleanup.sh --local-only --dry-run
```

※ JSON 形式で構造化データを取得して処理したい場合は `--json` フラグを付与できます。

### ステップ 2: 検出結果の提示と確認

検出結果を以下のフォーマットでユーザーに分かりやすく提示します：

```markdown
### 📋 Git クリーンアップ候補（Dry-Run）

**対象リポジトリ:** `/path/to/repo`
**デフォルトブランチ:** `main`

#### 🗑️ 削除予定の項目
- **ローカルブランチ & Worktree:**
  - `feat/login-flow` (merged into main) `[Worktree: ../worktrees/login]`
  - `fix/typo` (gone: リモート削除済み)
- **リモートブランチ (origin):**
  - `origin/feat/login-flow` (merged into main)

#### ⚠️ スキップ・保護された項目
- `feat/wip-experiment`: Worktree に未コミット変更があるため保護

---
上記の内容で削除を実行してよろしいですか？
```

### ステップ 3: ユーザー承認後の実行

ユーザーから「実行してください」「はい」などの承認を得たら、`--execute` を付与して削除を実行します。

```bash
# ローカルブランチ + クリーンな Worktree + リモートブランチの削除 (デフォルト)
.agents/skills/git-cleanup/scripts/cleanup.sh --execute

# ローカルのみ削除する場合
.agents/skills/git-cleanup/scripts/cleanup.sh --local-only --execute
```

### ステップ 4: 完了報告

削除完了後のサマリー（削除されたブランチ名、Worktree数、リモートブランチ数）を簡潔に報告します。

---

## 🛠️ CLI オプション一覧

スクリプトはターミナルから手動で実行することも可能です。

| オプション | 短縮形 | 説明 |
| :--- | :--- | :--- |
| `--dry-run` | `-n` | 削除候補の一覧表示のみを行い、削除はしない（デフォルト） |
| `--execute` | `-e` | 安全チェックを通過した対象を実際に削除する |
| `--local-only` | `-l` | リモートブランチを除外し、ローカルブランチ/Worktreeのみを対象にする |
| `--include-remote`| `-r` | リモートブランチも含めて対象にする（デフォルト） |
| `--json` | `-j` | 結果を機械可読な JSON 形式で出力する |
| `--dir <PATH>` | `-C` | 対象 Git リポジトリのルートパスを指定する（省略時はカレントディレクトリ） |
| `--help` | `-h` | ヘルプメッセージを表示する |
