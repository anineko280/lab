# コードベースツアー ＆ ステップ解説スキル

このスキルは、プロジェクトやサブシステムのコードベースを **「初心者にも分かりやすく、かつ技術的に本質的な深さを持って1ファイルずつ対話形式で案内し、リポジトリ内に永続ドキュメントとして記録する」** ためのガイドラインです。

---

## 🧭 全体ワークフロー

```
【フェーズ1: 構造把握とロードマップ作成】
   │  実行・描画順序を特定して番号順の計画を提示
   ▼
【フェーズ2: 1ファイルずつの対話型深掘り解説】
   │  コードの意味、内部挙動、「無いとどうなるか？」を解説
   ▼
【フェーズ3: 図解（Mermaid）の使い分け】
   │  チャット内はテキスト/ASCII図、docs内はMermaid
   ▼
【フェーズ4: docs/TOUR.md への永続化】
   └─ 解説内容・Q&Aをプロジェクト内の docs/TOUR.md に集約・更新
```

---

## ステップ 1: 実行順序に沿ったロードマップ作成

ファイル名のアルファベット順ではなく、**「ブラウザやプログラムが実際に実行・描画する順番」** に沿ってロードマップを作成します。

### 例: Webフロントエンド（React / Vite）の場合
1. **`index.html`** ：ブラウザが最初に読み込む土台HTML・メタタグ
2. **`src/main.tsx`** ：React起動エントリーポイント・DOMマウント
3. **`src/App.tsx`** ：ページ全体の司令塔（レイアウト・コンポーネントツリー）
4. **`src/data/`** ：マスターデータ層・TypeScript型定義
5. **`src/styles/`** ：デザイントークン（CSS変数）・共通リセット・アニメーション
6. **`src/components/`** ：共通コンポーネント基盤（BentoCardなど）
7. **個別機能コンポーネント** ：各セクションのUI部品
8. **設定・ツールチェーン** ：`tsconfig` 3兄弟、Linter（Oxlint）、`package.json`

ロードマップを作成したら、ユーザーに全体像を示して **ステップ1から開始** します。

## ステップ 2: 1ファイルごとの解説フォーマット

各ファイルを解説する際は、以下の観点を網羅して解説します：

1. **一言での役割**: このファイルが何をしているのかを平易な言葉で説明。
2. **コードの抜粋と重要箇所の解説**: 該当コードを示しながら処理の流れを解説。
3. **本質的な技術的背景の深掘り**:
   - **「無いとどうなるか？」**（エラーになるのか、表示が崩れるのか、セキュリティリスクか）
   - **「なぜこの設計なのか？（他の書き方との比較）」**（例: クラス vs インターフェース、CSS vs CSS-in-JS、ESLint vs Oxlint）
   - **「必須か？任意か？」**
   - ブラウザやランタイムの内部動作（DOMツリー構築、CORS通信、GPUアクセラレーション、Reactの並行レンダリング等）
4. **対話的な確認**: 1ファイル解説したら「気になるところや質問はありますか？」と確認し、疑問を解消してから次のファイルに進む。

## ステップ 3: 図解（Mermaid）の使い分けルール【最重要】

- **💬 チャット画面での回答時**:
  - チャット内では生の ````mermaid ```` コードブロックは **使用しない**（プレビューが効かずコード文字列が表示されてしまうため）。
  - 代わりに、**視認性の高いテキスト図、ASCIIツリー、箇条書きのフロー** を使って分かりやすく図解する。
- **📄 Markdownファイル（`docs/TOUR.md` 等）**:
  - エディタの Markdown プレビュー（`Cmd+Shift+V`）でカラー図解が表示されるよう、**積極的に ````mermaid ```` 構文（シーケンス図・フローチャート・状態遷移図）** を使って記述する。

---

## ステップ 4: `docs/TOUR.md` への永続化

解説した内容や対話で生まれた Q&A は、一時的なアーティファクトで終わらせず、**リポジトリ内の永続ドキュメント** として保存・更新します。

- **保存先パス**: `<対象プロジェクト>/docs/TOUR.md`（例: `profile/docs/TOUR.md`）
- **ドキュメント構成**:
  - 進捗チェックボックス付きのロードマップ
  - 各ファイルの完全なコード抜粋・解説・Mermaid図解
  - ユーザーから受けた質問と回答をまとめた **「徹底Q&Aまとめ」**
  - ファイル間の相対リンクは、`docs/` から見て正しく飛べるよう `../` に調整する
