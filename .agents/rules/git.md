# Git コミットメッセージ規約 (Git Commit Rule)

Gitのコミットメッセージは、常に**日本語**で記述してください。

## 適用ルール
1. **記述言語**:
   - コミットメッセージのタイトルおよび詳細説明は、原則として**日本語**で記述します。

2. **形式（推奨）**:
   - プレフィックス（`feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:` 等）を付与し、それに続けて日本語で変更概要を簡潔に記述します。
   - 例: `docs: .agents/rules にコミットメッセージ規約を追加`
   - 例: `feat: ログイン機能の実装`

3. **プッシュ前の派生元ブランチ (Rebase) 確認**:
   - リモートリポジトリへ `push` する前は、必ず派生元ブランチ（通常は `origin/main`）の最新コミットを確認・取得 (`git fetch origin`) し、必要に応じて `git rebase origin/main` を実行するか、ユーザーに確認してください。
